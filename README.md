# AI-Based Ride-Hailing Demand Prediction and Service Optimization

ML Capstone Project repo containing EDA, feature engineering, 10 regression models, and 5 classification models.

## Dataset

The project uses the NYC Yellow Taxi Trip Records dataset.

Download the dataset and place the Parquet file in the appropriate project directory before running the notebook.

Dataset source: NYC Taxi & Limousine Commission (TLC).
